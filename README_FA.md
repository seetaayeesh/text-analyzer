# تحلیل‌گر متن

[English guide](README.md)

یک خط متن وارد کنید تا تعداد نویسه‌ها و واژه‌ها، پرتکرارترین موارد و تعداد تکرار هر کدام را ببینید.

## نصب سریع در اوبونتو

دستور زیر را در ترمینال اجرا کنید. به `curl` و پایتون ۳٫۸ یا جدیدتر نیاز دارید.

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/seetaayeesh/text-analyzer/main/install.sh | bash'
```

بعد از نصب، برنامه را با این دستور اجرا کنید.

```bash
~/.local/bin/text-analyzer
```

نصب در پوشهٔ خانگی شما انجام می‌شود. برای به‌روزرسانی، همان دستور نصب را دوباره اجرا کنید. اگر ابزارهای لازم را ندارید، ابتدا `sudo apt update && sudo apt install curl python3` را اجرا کنید.

## اجرا

به پایتون ۳٫۸ یا جدیدتر نیاز دارید. در ویندوز، از پوشهٔ همین پروژه دستور زیر را اجرا کنید.

```powershell
py main.py
```

در لینوکس یا مک از `python3 main.py` استفاده کنید. برنامه به نصب بستهٔ اضافی نیاز ندارد.

## نمونه

برای ورودی `سلام، سلام!`، برنامه ۱۱ نویسه و ۲ واژه می‌شمارد. پرتکرارترین واژه «سلام» است که دو بار تکرار شده است. فهرست کامل فراوانی‌ها هم چاپ می‌شود.

اگر برنامه خطای کدگذاری ورودی نشان داد، متن را دوباره در ترمینالی با کدگذاری UTF-8 وارد کنید.

## کد چگونه می‌شمارد؟

- فاصله‌های ابتدا و انتهای متن حذف می‌شوند. فاصله‌ها و نشانه‌های داخل متن در تعداد کل نویسه‌ها حساب می‌شوند.
- در فهرست فراوانی نویسه‌ها، فاصله و تب شمرده نمی‌شوند. واژه از حروف یا رقم‌ها تشکیل می‌شود و نیم‌فاصله می‌تواند بخش‌های یک واژه را به هم وصل کند.
- برنامه ابتدا حروف را به شکل کوچک تبدیل می‌کند و سپس با `Counter` تعداد تکرارها را می‌شمارد. موارد پرتکرارتر اول می‌آیند و موارد هم‌تعداد بر اساس ترتیب رشته‌ها در پایتون مرتب می‌شوند.
